# Flash — on-device regression checklist

This checklist was generated by walking the live repository on this branch — every row was read out of the current Dart sources (`lib/screens`, `lib/widgets`, `lib/services`, `lib/repositories`, `lib/app.dart`) and the four commits landed on 2026-09-08, not from `PRD-Flash.md`, not from `MANUAL_QA.md`, and not from memory of previous audits. Where the code and an older document disagree, the code is what is written down here; where two places in the code disagree with each other, both readings are recorded and the row asks the tester to say which one actually happens. Expected results describe what the current build does, including behaviour that looks wrong — those rows are marked so they can be judged rather than silently "passed".

**Re-validated 2026-09-08** against everything now on
`perf/tablet-samsung-audit-2026-09-08`: the refresh-settings move (`5b81aa4`),
the clean-mode extraction fixes (`b3e8274`), the reverted 2d retire guard
(`adee50e`, no user-visible change), and Impeller staying OFF. Rows 3, 18, 22,
24, 27, 290 and 322 were rewritten in place; rows 379-385 left the Quick
Settings section — the interval picker is not in that bubble any more — and are
reproduced, rewritten, in the new **Refresh** section at the end together with
rows 487-513. The real row count is **486** before that section, not 516.

**Devices.** *Tablet* = Lenovo Tab M11 (TB330FU), 800x1280dp — landscape reaches the 840dp three-column tier, portrait only the 600dp rail tier. *Samsung* = Galaxy M51 (360dp, phone tier). Pixel-only rows say so in Notes. Leave both device columns empty until run; use `pass`, `fail`, `n/a`, or a note.

**Tags in the Action cell**

- **DESTRUCTIVE** — writes or deletes app data (read state, bookmarks, feeds, keywords, backups). Not reversible from inside Flash unless the row says so.
- **BLOCKED (system UI)** — needs a surface outside Flash (launcher, share sheet, file picker, Google consent, notification shade, system language/font/theme, force-stop). Per the project rules these cannot be driven from this session; run them by hand or on an emulator.
- **TABLET-ONLY** — only observable at 600dp+ (rail) or 840dp+ (three columns).
